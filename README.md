# RecipeBook 🍽️

## Про проєкт

**RecipeBook** — це крос-платформний мобільний додаток «Кулінарна книга», розроблений за допомогою React Native та Expo.

Мета проєкту — створити зручний мобільний застосунок для перегляду кулінарних рецептів, пошуку страв та керування списком користувачів.

## Реалізовані можливості

### 📖 Робота з рецептами
- Перегляд кулінарних рецептів.
- Поділ рецептів на категорії: сніданки, обіди, вечері та десерти.
- Пошук рецептів.
- Перегляд детальної інформації про страви.
- Додавання рецептів до обраного.

### 👤 Керування користувачами
- Перегляд списку користувачів.
- Додавання нових користувачів.
- Редагування особистих даних.
- Видалення користувачів.
- Введення імені, електронної пошти та номера телефону.

### 💾 Збереження даних
Для локального збереження інформації використовується AsyncStorage. Дані користувачів зберігаються на пристрої та відновлюються після повторного запуску додатку.

## Використані технології

- React Native
- Expo
- TypeScript
- AsyncStorage
- Visual Studio Code

## Запуск проєкту

1. Завантажити або клонувати репозиторій.
2. Відкрити папку проєкту у Visual Studio Code.
3. Встановити залежності:

```bash
npm install
```

4. Запустити додаток:

```bash
npx expo start --tunnel
```

5. Відкрити застосунок на телефоні через Expo Go.
